# 山清工業㈱生産数集計

便ごとにQRを読み取り、品番別の箱数・出荷数（個）を集計して、山清工業㈱生産数報告書のExcelを出力するツールです。

- 本体は HTML 1ファイル（`index.html`）です。`sw.js`・`manifest.json`・アイコンは、オフラインで開くためのファイルです。
- タブレットでは、最初に1回ネットにつながる場所で GitHub Pages のURLを開きます。そのあとはオフラインでも同じURLで開けます。
- 更新は、ネットにつながる場所で開いたときに自動で入ります。
- 使い方は、ツールの「設定・データ管理」→「使い方手順書」にあります。
- 開発の引き継ぎ・仕様は [CLAUDE.md](CLAUDE.md) を見てください。
- 自動テスト：`bash tests/run_all.sh`
